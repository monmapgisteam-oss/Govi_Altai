# Говь-Алтай — Нийгмийн дэд бүтцийн хүртээмжийн атлас

Говь-Алтай аймгийн **сургууль, цэцэрлэгийн хүртээмж** болон **авто замын хүртээмж**-ийг
ArcGIS Business Analyst-ийн шинжилгээний логикоор тооцоолж, Next.js дээр харуулсан веб апп.

Эх өгөгдөл: [ArcGIS вэб газрын зураг `e5166cb6feab4301b7dc70de3bca6347`](https://monmap.maps.arcgis.com/apps/mapviewer/index.html?webmap=e5166cb6feab4301b7dc70de3bca6347)
— бүх feature layer-ийн attribute утгыг REST API-аар шууд татаж ашигладаг.

---

## Хурдан эхлэх

```bash
npm install
npm run data     # ArcGIS-ээс өгөгдөл татаж, шинжилгээ хийж public/data/ руу бичнэ
npm run verify   # тоо бүрийг ArcGIS эх сурвалжтай тулгаж шалгана
npm run dev      # http://localhost:3000
```

Production:

```bash
npm run build && npm start
```

`npm run data` нь ~15 секунд ажиллаж, дараах файлуудыг үүсгэнэ:

| Файл | Агуулга |
| --- | --- |
| `public/data/meta.json` | Давхаргын жагсаалт, параметр, босго утга |
| `public/data/aimag.json` | Аймгийн нэгтгэсэн үзүүлэлт, цуваа, улсын харьцуулалт |
| `public/data/soums.json` | 18 сумын бүх метрик, индекс, эрэмбэ |
| `public/data/camps.json` | 9 850 бууцны багана хэлбэрийн ойролцоо байдлын хүснэгт |
| `public/data/geo/*.geojson` | Хил, зам, сумын төв (ерөнхийчилсөн геометр) |

## Layout

Бүх хуудас **нэг дэлгэцэнд багтсан** (page scroll байхгүй): `lg` ба түүнээс дээш
дэлгэцэнд `h-screen` shell дотор 12 баганат grid ашиглан панель бүр үлдэгдэл өндрийг
хуваан эзэлнэ. Урт хүснэгт, жагсаалт зөвхөн панелийн дотор гүйнэ. Жижиг дэлгэц дээр
хэвийн scroll руу шилжинэ.

## Шинжилгээний логик (ArcGIS Business Analyst-ийн дүйцэл)

| BA хэрэгсэл | Энэ төсөл дэх хэрэгжилт |
| --- | --- |
| Demand / Supply points | Өвөлжөө-хаваржаа = эрэлт, сумын төв = нийлүүлэлт |
| Near (Proximity) | `SegmentIndex` — хэрчмийн жигд торон индекс, O(1) хайлт |
| Simple Rings | Зайн бүсчлэл: сургууль 10/25/50/80, цэцэрлэг 5/15/30/50, зам 2/5/10/20 км |
| Enrich | Бүс тус бүрийн бууц + өрхийн нэгтгэл |
| Supply/Demand accessibility | **E2SFCA** — Гауссын саарлалттай хоёр шатлалт хөвөгч катчмент |
| Composite scoring | Хамралт + E2SFCA + зай + нягтшилийг жигнэсэн 0–100 индекс |

Нийгмийн дэд бүтэц гурван багана: **сургууль, цэцэрлэг, эмнэлэг**. Гурвуулаа сумын
төвд байрладаг тул зайн гишүүн ижил, зөвхөн нэг хүнд ногдох нийлүүлэлт (E2SFCA)
ялгаатай. Эрүүл мэндэд зөвхөн **эмчилгээ үзүүлдэг 52 байгууллага** орно — эмийн сан,
эм ханган нийлүүлэх байгууллага, «бусад» ангилал хасагдсан.

```
боловсрол = 0.55·сургууль + 0.45·цэцэрлэг
нийгмийн ДБ = 0.5·боловсрол + 0.5·эрүүл мэнд
нэгдсэн = 0.5·нийгмийн ДБ + 0.5·зам
```

Дэлгэрэнгүй томьёо, таамаглалыг апп доторх `/methodology` хуудаснаас үзнэ үү.

### Гол таамаглалууд

- Сургууль, цэцэрлэгийн тоо зөвхөн **аймгийн түвшинд** байдаг тул сум бүрд 1 нэгж суурьтайгаар,
  үлдэгдлийг **хүн амд** пропорциональ (largest remainder) хуваарилсан. Хүртээмжийн эрэлтийг
  мөн хүн амаар жигнэсэн — бууцанд малчин хүн ам, сумын төвд суурин хүн ам.
- Малтай өрхийг бууцны тоонд жигд хуваарилсан (1 бууц ≈ 1.07 өрх).
- Зайг шулуунаар тооцсон; явах хугацааг замын ангилалын хурд + 1.3 тойролтын коэффициентоор
  **ойролцоогоор** үнэлсэн (Network Analyst ашиглаагүй).

## Газрын зураг

Газрын зургийг **ArcGIS Maps SDK for JavaScript** нь эх вэб газрын зургийг
`portalItem` -оор шууд ачаалж зурдаг. Тиймээс Map Viewer дээр хийсэн **style,
символ, суурь зургийн өөрчлөлт апп дээр шууд тусна** — код өөрчлөх шаардлагагүй,
хуудсаа сэргээхэд л хангалттай.

Үүн дээр нэмэгдэх цорын ганц зүйл бол вэб газрын зурагт байх боломжгүй
**тооцоолсон** давхарга:

| Давхарга | Эх сурвалж |
| --- | --- |
| Сумын хүртээмжийн зэрэглэл | `public/data/geo/soums.geojson` (тооцоолсон индекс) |
| Бууц зайн бүсээр | `public/data/camps.json` |

Энэ хоёр давхарга **5 шатлалын хүртээмжийн өнгийг** ашиглана — Маш сайн ▸ Сайн ▸
Дунд ▸ Хангалтгүй ▸ Маш хангалтгүй. Ижил таван өнгө чарт, хүснэгт, тэмдэглэгээнд
давтагдана. Давхаргын самбараас вэб газрын зургийн жинхэнэ давхаргуудыг өөрсдийнх нь
нэрээр асаа/унтраах, эсвэл шинжилгээний давхаргыг унтрааж зөвхөн эх загварыг харах
боломжтой.

Апп нь вэб газрын зургийн **давхаргын нэр, харагдах эсэхэд огт хөндлөнгөөс оролцохгүй** —
Map Viewer дээр асаасан давхарга апп дээр асаалттай ирнэ, нэр солиход апп дагаж өөрчлөгдөнө.
